ParlerVoice

Expressive TTS fine‑tuned on ~650h — based on Parler‑TTS Mini v1.1

GitHub README

Introduction

ParlerVoice is an open‑source, expressive text‑to‑speech model from VoicingAI RnD Labs. We fine‑tuned parler-tts-mini-v1.1 on ~650 hours of curated audio for clearer timbre, better pacing, and more controllable style.

Usage

pip install -r requirements.txt
python gradio_app.py --checkpoint "/path/to/ckpt_or_repo" --base-model "parler-tts/parler-tts-mini-v1.1" --share
